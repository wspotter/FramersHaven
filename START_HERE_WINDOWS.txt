FramersHaven - Windows Start Here

This is a release-candidate Windows ZIP/folder workflow for local-first custom framing shops.
It does not include vendor catalogs, customer records, accounting credentials,
or online billing.

Release-candidate features and packaging may still change after Windows validation.
No payment processing, email/SMS sending, or accounting API sync is included.
Do not expose this app directly to the public internet.

Install
1. Download FramersHaven-Setup.exe from the official FramersHaven release.
2. Open it and finish setup.
3. Launch FramersHaven from the Start menu or desktop.

No Python, Git, administrator rights, or command-line setup is required.

If Windows displays "Windows protected your PC", confirm the file came from
the official wspotter/FramersHaven release, click More info, and click Run
anyway. Do not bypass warnings for files from unofficial links.

Restarting
- Open FramersHaven from the Start menu or desktop.
- Starting it again reopens the running local app.

Optional Local AI
- The basic app works without Ollama or a model.
- To add Framewise vision, run setup_ai_windows.ps1 from the FramersHaven
  program folder in PowerShell.
- Then open Admin > Framewise in the app, enable it, and click Save and Test.

Network Use
- The packaged app listens on the local machine only.
- Do not expose FramersHaven directly to the public internet.

Data Location
- Customer data is stored under %LOCALAPPDATA%\FramersHaven\Data.
- Updates and uninstall/reinstall preserve that folder.
- Use the in-app backup before moving to another workstation.

Support
- This is a local-first release candidate.
- See docs/WINDOWS_INSTALL.md and docs/USER_MANUAL.md for details.
- See CHANGELOG.md for release notes.
